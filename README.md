# DashBot

לוח בקרה אינטראקטיבי בעברית (RTL) למנהל רפואי אזורי — ניהול כוח אדם, שיחות משוב, משימות, איכות קלינית ופניות ציבור.

## מה כלול

1. **כוח אדם** — רשימת רופאים, פערי שיבוץ, וצינור גיוס עם שלבים לכל מועמד  
2. **שיחות ניהול** — מעקב שיחות משוב (שנתי לראשונית / דו־שנתי ליועצים) עם סטטוס באיחור / קרוב / בקרוב  
3. **משימות** — דחופות וחוזרות, יצירה / השלמה / סינון  
4. **איכות קלינית** — מדדי KPI עם פירוט לפי מרפאה  
5. **פניות ציבור** — מעקב SLA עד שבועיים, כולל תודות וסטטיסטיקה לפי רופא  

הנתונים הם mock מקומיים (ללא auth / DB).

## הרצה מקומית

```bash
npm install
npm run dev
```

האפליקציה נפתחת ב־[http://127.0.0.1:43127](http://127.0.0.1:43127).
